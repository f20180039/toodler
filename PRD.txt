The Workflow Builder
The Workflow Builder helps schools create workflows across admissions, marketing and enrolment. For this assignment, candidates only need to build the workflow creation experience; workflow execution is outside the scope.

Basic workflow nodes
These nodes are used in the examples below.
Trigger
Starts the workflow when something happens.

Send email
Sends a message to a family or the school team.

Delay
Waits before moving to the next step.

Branch
Continues the workflow only when a condition matches.
